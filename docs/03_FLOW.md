# 系统流程

## 文本模式

1. 用户输入文本
2. 调用 LLM
3. 返回结果
4. 显示UI

---

## 语音输入模式

1. 点击语音按钮
2. 申请麦克风权限
3. Vosk STT 离线识别
4. 识别文本回填输入框
5. 用户确认后发送给 LLM
6. 返回结果

说明：STT 输入不自动发送，用户可编辑识别结果后再发送。

---

## 语音播放模式

1. AI 返回结构化结果
2. 用户点击 AI 消息下方的播放按钮
3. Android System TTS 播放 `【自然回应】` 中的日语内容

---

## LLM处理流程

用户输入 → Prompt包装 → LLM推理 → 返回结构化文本
